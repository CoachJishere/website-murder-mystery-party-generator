## TRANSLATION METHODOLOGY USED

### Approach:
1. Read source JSON for each post
2. Translate using Claude Code direct capabilities (no external API)
3. Apply French E-E-A-T footer
4. Maintain all markdown formatting
5. Adapt cultural references and idioms
6. Save as markdown with frontmatter metadata

### Why This Method:
- **Quality Control:** Direct review of each translation
- **Consistency:** Same translator = consistent voice
- **No API Issues:** Avoids authentication problems
- **Cultural Accuracy:** Better idiom and phrase localization
